# BREQ002 Create personal site for business

## GOALS
User should have an option to create their personal accounts. This account will be for a person or for a business offering products, services, goods or others.

## ACCESS REQUIREMENTS AND GRANTS
The page to create 

## UI REQUIREMENT
The option to create an account should be displayed in the web site's main page at the top on a tools bar with the label "Create account".

When the user clicks the "Create account" option it should be redirected to a wizard option with the following steps:

* Request "Are you a person or a business?"
  * If a person:
    * Request "Please provide your full name" 
  * If a business:
    * Request "Please provide the name of your business"
    * Request "Is your business a brick-and-mortar establishment?"
      * If yes:
        * Request "Please provide the full address of your business"
  * Request "Please provide your contact phone numbers separated by a comma"
  * Request "Please indicate contact days and hours"
  * Request "Please indicate the services or products you provide separated by a comma"
